# AttenRegister

A desktop student attendance management and reporting system developed in C# and .NET Windows Forms.

## Overview
- Platform: Windows Desktop (.NET Framework, Windows Forms)
- Database: SQL Server
- Reporting: SAP Crystal Reports (.rpt)

## Features
- Student directory registration and cohort filtering.
- Daily attendance logging with immediate present/absent tracking.
- Formal report generation and individual attendance transcripts via Crystal Reports.
